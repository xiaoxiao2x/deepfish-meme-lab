# 全栈 Python，不复用 deepWhale-MemeHub 的 Node 工具

工作台（含将来的 Web UI）一律用 Python：Pillow 做图像拼装、ffmpeg 子进程做 GIF、FastAPI + Jinja2 + htmx 做页面。

这条决定要记，因为**它主动放弃了已经写好并验证过的代码**：同一作者的 deepWhale-MemeHub 里有一套 `.cjs` 工具（变体生成、视觉去重、清单更新），本项目的素材处理需求与它们几乎重合。选择重写而不是复用，理由是技术栈统一的价值高于复用——一个自用工具引入两套运行时、两套依赖管理，长期维护成本高于一次重写。

代价也记清楚：那套工具的**行为**被保留为规范参考（三级去重的判定阈值、480/1600 两档尺寸、清单字段语义），去重环节改用素材目录里现成的 Python 脚本后净损失接近零。将来若要改回 Node 生态，得重新对齐一遍。
