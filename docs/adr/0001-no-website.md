# 不做网站，站点能力全部出局

本期产品形态确定为本机应用（Python 起本地服务、浏览器打开），**不做任何面向公网的站点能力**：不接 Cloudflare R2、不用已备案域名、不引托管或 CDN。作者原话是"先做成 PC 上的应用，暂时不考虑网站"。

这条非目标值得记下来，因为**它放弃的是现成的能力**：同一作者的 deepWhale-MemeHub 已经打通了「R2 + 备案域 + 上传脚本」的发布链路，而本项目的产出天然是那条链路的上游——接上去是顺手的事。将来若要共享，产物仍然可以走那条既有链路，但本期**不实现、不设计、不预留接口**。

配方条目里保留 `src` / `preview` / `large` 三个恒为 `null` 的字段，是零成本的语义占位（沿用下游清单的同名字段以便将来对接），**不是**为站点预留的接口。
